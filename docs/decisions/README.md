# Architecture decisions

I keep short ADRs here for choices that affect more than one module. The goal is to preserve the reasoning behind a decision, not to make every implementation detail permanent.

- [ADR 001 — Keep personal data local by default](001-local-first-data.md)
- [ADR 002 — Separate desktop integration from the Python core](002-electron-python-boundary.md)
- [ADR 003 — Native actions must be controlled and verifiable](003-controlled-native-actions.md)

A decision can be replaced later. If that happens, the old ADR should remain and point to the newer one so the project history is understandable.
